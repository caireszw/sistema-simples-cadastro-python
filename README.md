# sistema-simples-cadastro-python
Sistema simples de cadastro desenvolvido em Python, utilizando listas e lógica de programação para adicionar, listar e buscar usuários. Projeto focado no aprendizado de estruturas básicas como loops, condicionais e manipulação de dados.

*Funcionalidades
*Cadastrar usuários
*Listar usuários cadastrados
*Buscar usuário pelo nome
*Menu interativo no terminal
